# Part 1: MVP Landing Page

This part focuses on creating the public-facing entry point of the SaaS platform. The landing page will pitch the value proposition to business owners and provide the input field to accept their Google Maps links.

## Proposed Architecture
- **Framework**: Next.js App Router.
- **Styling**: Vanilla CSS for a premium, custom aesthetic.
- **Key Components**:
  - `Hero Section`: Highlighting the "Instant Brochure" value proposition with micro-animations.
  - `Input Component`: A stylized input field that accepts a Google Maps URL or place search and triggers the generation flow.
  - `Preview Section`: A static mockup or carousel showing examples of what the generated brochures look like.

## Architecture & Integration
- This page will act as the frontend gateway. Once the user submits a link, it will trigger the backend scraper (Part 2).
